# Accessibility and responsive baseline

The MVP routes use semantic headings, labelled form controls, visible keyboard focus, text labels alongside performance colors, and responsive table overflow rather than clipped data. Country table rows support Enter and Space; map controls and the listed mapped-country links are keyboard reachable. Map values have a text legend and a details panel, so colors are never the only source of performance meaning.

Before release, check each route at 1280px and 375px widths; use Tab/Shift+Tab to reach all controls, Enter/Space to activate country rows, and a screen reader to verify headings, table captions, status messages, and destructive-action confirmation. Reduced-motion preferences suppress nonessential transitions.
